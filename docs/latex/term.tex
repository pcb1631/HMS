Every terminal has different behaviour when running and debugging HMS/\+ncurses, due to the the fact that terminals don\textquotesingle{}t seem to agree on one ANSI escape code standard

As such we have compiled a list of terminals we tested and their behaviour.

{\bfseries{In case the program crashes, ncurses will not be able to call endwin(), and the terminal will most likely be broken because it can\textquotesingle{}t revert ANSI escape codes. (e.\+g. if you see strange characters when you backspace or press enter during login)}} {\bfseries{If this happens:\+}} 
\begin{DoxyCode}{0}
\DoxyCodeLine{reset}

\end{DoxyCode}
 {\bfseries{This will reset the terminal to it\textquotesingle{}s usual state.}}
