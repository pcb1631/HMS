\doxysection{How to use HMS }
\hypertarget{usage}{}\label{usage}\index{How to use HMS@{How to use HMS}}
TIP:\+ Do CTRL+C (sigint) to exit the program or cancel an operation

The binary only requires the DB folder and credentials file, and you can name the binary whatever you want

{\bfseries{It\textquotesingle{}s very important that the binary is in the same dir as your DB file!}}

~\newline
 This will show the menu first:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{./main.out}

\end{DoxyCode}


~\newline
 To go straight to login or register:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{./main.out\ login}

\end{DoxyCode}
 
\begin{DoxyCode}{0}
\DoxyCodeLine{./main.out\ register}

\end{DoxyCode}


~\newline
 To login into an account 
\begin{DoxyCode}{0}
\DoxyCodeLine{./main.out\ login\ [username]}

\end{DoxyCode}
