The Hospital Management System (HMS for short) is an interactive program to facilitate hospital documentation, appointment booking, among other services. HMS is designed to run in every major OS, as it is written purely in ANSI C\hypertarget{index_installation}{}\doxysection{\texorpdfstring{Installation /\+ Compiling}{Installation /\+ Compiling}}\label{index_installation}
HMS was primarily developed for linux, so it is reccomended to use WSL if you\textquotesingle{}re on Windows.

Clone the repo:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{git\ clone\ https://github.com/pcb1631/HMS}

\end{DoxyCode}


Add git submodules:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{git\ submodule\ update\ -\/-\/init\ -\/-\/recursive}

\end{DoxyCode}
\hypertarget{index_autotoc_md0}{}\doxysubsection{\texorpdfstring{Linux/\+\+Mac\+OS}{Linux/\+\+Mac\+OS}}\label{index_autotoc_md0}
ncurses is shipped with most linux distros, while ncurses 6.\+x is shipped with Mac\+OS Sonoma and later


\begin{DoxyEnumerate}
\item make
\begin{DoxyItemize}
\item make should come with xcode if you\textquotesingle{}re using Mac\+OS. If not, install make with homebrew 
\begin{DoxyCode}{0}
\DoxyCodeLine{brew\ install\ make}

\end{DoxyCode}

\end{DoxyItemize}
\end{DoxyEnumerate}

Use the provided Makefile to compile the project:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{make}

\end{DoxyCode}


When making changes in files other than \doxylink{main_8c}{main.\+c}, delete the binary and run make again:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{make\ clean;\ make}

\end{DoxyCode}

\end{DoxyCode}
 Then, use the Makefile to compile:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{./make}

\end{DoxyCode}
